# ボス/ミッション系の扱いメモ

Status: Supporting

- 旧ボス（ミッション経由の即時スポーン）は無効化済み。`assets/data/system/game.json` の `mission` パスを空にしてあり、ステージ側のトリガー（時間/拠点封鎖）でドラゴンを出す方式に統一。
- ミッション/Bossのコードは今後別ボスで使う可能性に備えて残している。再利用する場合は `mission` に新ファイルを指し、スポーン/機構を新仕様に合わせて構成し直すこと。
- ステージ進行がメイン前提なので、ミッションを再度有効にする場合は二重スポーンや勝利条件の重複に注意すること。 
- 現行運用ルール（採用済み案）
  - スポーン: ゴーレムは150秒経過 or 敵拠点1封鎖で1体、ドラゴンは300秒経過 or 敵拠点2封鎖でスポーン。ドラゴンは未封鎖の敵拠点位置を優先して出現。
  - 勝利条件: 「ドラゴン撃破」かつ「全敵拠点封鎖」の両方必須（`stage.victory` を強制上書き）。
  - 行動指針: スライム=最寄り味方追尾、ゴーレム=拠点寄りで近接味方を優先、ドラゴン=拠点へ進軍しつつ近距離の味方を蹴散らす。
